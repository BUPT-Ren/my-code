智阅同行

校园图书共享系统项目汇报

一、项目背景与需求分析

1.1 项目概述

智阅同行是一个面向校园的智慧图书共享平台，由北京邮电大学与北邮附中联合共建。系统整合了Web管理平台和微信小程序双端应用，旨在搭建连接大学资源与中学需求的智慧阅读桥梁。

1.2 前期调研

为支撑项目核心需求分析，针对北邮附中师生开展问卷调研，回收教师问卷24份、学生问卷92份。调研结果如下：

1.3 需求总结

  • 教师端需求：整合化资源平台、学科适配的阅读资源、跨学科拓展素材
  • 学生端需求：便捷的资源获取渠道、个性化阅读引导、纸质+电子双模式
  • 管理端需求：借阅流程管理、活动组织、数据统计分析

四、技术实现亮点

4.1 RESTful API 设计

后端采用Flask Blueprint实现模块化API设计，统一响应格式，支持Token认证和请求限流：

  • 统一响应格式：{"ok": true/false, "message": "...", "data": {...}}
  • Token认证：基于JWT的无状态认证
  • 请求限流：防止恶意请求（如登录限流5次/分钟）
  • CORS支持：跨域资源共享配置

4.2 数据库设计

系统包含15+核心数据表，覆盖用户、图书、借阅、活动、通知等业务实体：

users books borrow_records borrow_requests favorites activities activity_registrations notifications ai_chat_history admins

4.3 微信小程序开发

采用微信小程序原生框架开发，页面结构清晰：

  • TabBar导航：首页、活动、我的
  • 17个功能页面覆盖完整业务流程
  • 本地Token存储，自动携带认证
  • 下拉刷新、列表分页加载

4.4 AI推荐系统

基于用户借阅历史、收藏行为、浏览记录构建推荐模型：

  • 用户画像：兴趣爱好、阅读偏好分析
  • 协同过滤：相似用户推荐
  • 热门推荐：借阅排行、新书上架
  • AI对话：智能阅读问答助手

4.5 Docker容器化部署

提供完整的Docker部署方案：

  • Dockerfile定义应用镜像
  • docker-compose.yml编排服务
  • 环境变量配置分离
  • 一键启动部署
