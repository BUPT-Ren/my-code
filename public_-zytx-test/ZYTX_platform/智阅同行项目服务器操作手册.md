## 七、常用命令

```bash
# 进入项目目录
cd /opt/zytx/ZYTX_platform

# 启动所有服务
docker compose up -d --build

# 查看容器状态
docker compose ps

# 查看日志
docker compose logs -f

# 查看特定服务日志
docker compose logs -f flask

# 停止所有服务
docker compose down

# 重启所有服务

# 重启特定服务
docker compose restart flask

# 进入容器
docker compose exec flask bash
docker compose exec mysql mysql -u root -p

# 查看容器资源占用
docker stats
```

## 九、阿里云控制台常用操作

### 重置实例密码
1. 登录阿里云控制台
2. ECS → 实例与镜像 → 实例
3. 点击实例 ID 进入详情
4. 右上角「重置实例密码」
5. 设置新密码后重启实例

### 配置安全组
1. ECS → 实例 → 安全组
2. 配置规则：
   - 22 端口（SSH）
   - 80 端口（HTTP）
   - 443 端口（HTTPS）

### 获取 Docker 镜像加速地址
1. 登录阿里云控制台
2. 搜索「容器镜像服务」
3. 左侧菜单 → 镜像工具 → 镜像加速器
4. 复制你的专属加速地址

## 十、故障排查

### 问题1：无法连接服务器
- 检查安全组是否开放 22 端口
- 确认密码是否正确
- 确认实例是否在运行状态

### 问题2：Docker 镜像拉取超时
- 配置 Docker 镜像加速器
- 使用阿里云镜像加速地址

### 问题3：容器启动失败
```bash
# 查看容器日志
docker compose logs

# 查看容器状态
docker compose ps -a

# 检查端口占用
netstat -tlnp | grep -E '80|3306|5000'
```

### 问题4：数据库连接失败
- 确认 MySQL 容器是否正常运行
- 检查 .env 中的数据库配置是否正确
- 确认 DB_HOST 为 mysql（Docker 服务名）

## 十二、数据库迁移

当 `models.py` 有结构变更时，需要执行数据库迁移SQL。

### 检查是否有数据库变更

```bash
# 查看最新提交中是否修改了 models.py
git log -1 --name-only | grep models.py
```

### 执行数据库迁移

```bash
# 进入 MySQL 容器
docker compose exec mysql mysql -u zytx_user -p zytx
```

#### activity_registrations 表（签到功能）

```sql
ALTER TABLE activity_registrations 
ADD COLUMN check_in_time DATETIME NULL,
ADD COLUMN check_in_status ENUM('not_checked_in', 'checked_in') DEFAULT 'not_checked_in',
ADD COLUMN check_in_by INT NULL;
```

#### borrow_requests 表（取书确认）

```sql
ALTER TABLE borrow_requests 
MODIFY COLUMN status ENUM('pending', 'approved', 'picked_up', 'rejected') DEFAULT 'pending';
```

#### 退出 MySQL

```sql
exit
```

### 验证迁移成功

```bash
# 进入 MySQL 检查表结构
docker compose exec mysql mysql -u zytx_user -p zytx -e "DESCRIBE activity_registrations;"
docker compose exec mysql mysql -u zytx_user -p zytx -e "DESCRIBE borrow_requests;"
```

## 十三、数据库自动备份

### 备份配置

| 配置项 | 值 |
|--------|-----|
| 备份脚本 | `/opt/zytx/backup_db.sh` |
| 备份目录 | `/opt/zytx/backups/` |
| Git 仓库目录 | `/opt/zytx/db_backup_repo/` |
| Git 远程仓库 | https://gitee.com/Da_chen_l/ZYTX_db_backup.git |
| 定时任务 | 每天凌晨 3:00 执行 |
| 日志文件 | `/opt/zytx/backup.log` |
| 保留天数 | 7 天 |

### 查看定时任务

```bash
crontab -l
# 输出：0 3 * * * /opt/zytx/backup_db.sh >> /opt/zytx/backup.log 2>&1
```

### 查看备份日志

```bash
tail -50 /opt/zytx/backup.log
```

### 查看备份文件

```bash
# 查看备份文件列表
ls -lh /opt/zytx/backups/

# 查看备份文件大小（正常应该在几十KB以上）
ls -lh /opt/zytx/backups/*.sql.gz
```

### 验证备份内容

```bash
# 解压查看备份内容
zcat /opt/zytx/backups/backup_*.sql.gz | head -20

# 应该看到类似以下内容：
# -- MySQL dump 10.13  Distrib 8.0.27, for Linux (x86_64)
# -- Host: localhost    Database: zytx
# -- Table structure for table `activities`
```

### 手动执行备份

```bash
/opt/zytx/backup_db.sh
```

### 备份脚本关键配置

脚本位于 `/opt/zytx/backup_db.sh`，关键配置项：

```bash
DB_CONTAINER="zytx_mysql"    # MySQL 容器名称
DB_NAME="zytx"               # 数据库名
DB_USER="ldc"                # 数据库用户名（必须有备份权限）
DB_PASS='ldc1224601X#'       # 数据库密码
RETENTION_DAYS=7             # 保留天数
```

### 常见问题排查

#### 问题1：备份文件为空（20字节）

**症状**：
```bash
ls -lh /opt/zytx/backups/
# 显示文件大小只有 20 字节
zcat backup_*.sql.gz
# 无输出
```

**原因**：数据库用户名或密码错误，mysqldump 执行失败

**排查步骤**：
```bash
# 1. 检查数据库用户权限
docker exec zytx_mysql mysql -uldc -p'你的密码' -e "SELECT 1"

# 2. 手动测试 mysqldump
docker exec zytx_mysql mysqldump -uldc -p'你的密码' zytx | head -20

# 3. 检查脚本中的用户名密码
cat /opt/zytx/backup_db.sh | grep DB_USER
cat /opt/zytx/backup_db.sh | grep DB_PASS

# 4. 对比 .env 文件中的数据库密码
cat /opt/zytx/ZYTX_platform/.env | grep DB_PASSWORD
```

**解决方案**：修改备份脚本中的数据库用户名和密码

#### 问题2：Git 推送失败

**排查步骤**：
```bash
# 检查 Git 仓库状态
cd /opt/zytx/db_backup_repo
git status
git remote -v

# 检查 Git 配置
git config user.name
git config user.email
```

#### 问题3：定时任务未执行

**排查步骤**：
```bash
# 查看 cron 服务状态
systemctl status cron

# 查看 cron 日志
tail -100 /var/log/syslog | grep CRON

# 确认脚本有执行权限
ls -la /opt/zytx/backup_db.sh
chmod +x /opt/zytx/backup_db.sh
```

### 从 Git 仓库恢复备份

```bash
# 1. 克隆备份仓库
git clone https://gitee.com/Da_chen_l/ZYTX_db_backup.git

# 2. 选择要恢复的备份文件
ls -lh ZYTX_db_backup/

# 3. 解压并导入
gunzip < backup_20260325_171236.sql.gz | docker exec -i zytx_mysql mysql -uldc -p'密码' zytx
```
