# 校园图书共享小程序 - 设计规格文档

## 1. 项目概述

**项目名称**: 书香校园 (BookShare)  
**项目类型**: 微信小程序  
**目标用户**: 大学生群体  
**核心功能**: 图书共享借阅、收藏管理、AI阅读助手、阅读风格分析、活动报名

---

## 2. 视觉设计规格

### 2.1 色彩系统

| 色彩名称 | HEX 值 | 使用场景 |
|---------|--------|---------|
| 主色调（温暖棕） | #8B7355 | 导航栏、主要按钮、图标 |

| 成功色 | #7CB97C | 借阅成功、确认状态 |
| 警告色 | #E8A85C | 待处理、提醒 |

- **标题字体**: "Noto Serif SC", serif - 优雅有书卷气

  - 卡片标题: 28rpx
  - 正文: 26rpx

  - 小标签: 22rpx

### 2.3 间距系统

- 页面边距: 32rpx
- 卡片间距: 24rpx
- 组件内边距: 24rpx

### 2.4 圆角设计

- 大卡片: 24rpx

## 3. 页面结构

### 3.1 导航栏设计

采用底部 TabBar 导航，包含 5 个核心页面：
1. **首页** (index) - 图书浏览与搜索
2. **借阅** (borrow) - 我的借阅记录
3. **AI助手** (ai-assistant) - AI阅读助手
4. **报告** (reading-report) - 阅读风格报告
5. **我的** (profile) - 个人中心与收藏

### 3.2 页面详细设计

#### 3.2.1 首页 (pages/index/index)

**布局结构**:
- 顶部: 搜索栏 + 分类标签
- 中部: 轮播推荐位
- 主体: 图书网格列表（2列）
- 底部: 借阅热门榜单

**交互设计**:
- 下拉刷新图书列表
- 点击图书卡片跳转到详情页
- 长按可快速收藏

#### 3.2.2 图书详情页 (pages/book-detail/book-detail)

**布局结构**:
- 顶部: 图书封面（大图）
- 信息区: 书名、作者、出版社、ISBN
- 状态区: 可借数量、当前位置
- 操作区: 借阅按钮、收藏按钮
- 详情区: 简介、目录、评论

**借阅流程**:
1. 点击"申请借阅"
2. 选择取书时间（今天/明天/后天）
3. 填写联系方式
4. 确认提交
5. 显示成功提示

#### 3.2.3 收藏页面 (pages/favorites/favorites)

**布局结构**:
- 顶部: 收藏统计（数量、分类分布）
- 主体: 收藏图书列表
- 空状态: 引导去发现图书

**功能**:
- 取消收藏（滑动删除）
- 一键借阅收藏图书

#### 3.2.4 AI 阅读助手 (pages/ai-assistant/ai-assistant)

**布局结构**:
- 顶部: 对话记录列表
- 中部: 消息展示区（对话流）
- 底部: 输入框 + 快捷问题

**功能特性**:
- 智能问答（书籍推荐、阅读建议）
- 书摘提取
- 阅读计划制定
- 读书笔记辅助

**预设快捷问题**:
- "推荐几本治愈系书籍"
- "如何培养阅读习惯"
- "我想读历史，有什么好书"

#### 3.2.5 阅读风格报告 (pages/reading-report/reading-report)

**布局结构**:
- 顶部: 用户阅读数据总览
- 图表区: 
  - 阅读类型雷达图
  - 月度阅读折线图
  - 阅读时长饼图
- 分析区: 阅读偏好解读
- 推荐区: 基于风格的书籍推荐

**数据维度**:
- 阅读数量统计
- 分类偏好分析
- 阅读时段分布
- 阅读速度评估

#### 3.2.6 活动报名页面 (pages/activity/activity)

**布局结构**:
- 顶部: 轮播活动海报
- 分类: 线上/线下活动标签
- 主体: 活动列表（卡片式）

**活动卡片包含**:
- 活动封面图
- 活动名称
- 时间/地点
- 参与人数
- 报名状态按钮

**活动类型**:
- 读书会
- 作者见面会
- 线下交换活动
- 阅读马拉松

## 4. 组件设计

### 4.1 通用组件

1. **BookCard** - 图书卡片
   - 封面图
   - 书名、作者
   - 可借状态标签
   
2. **ActionButton** - 操作按钮
   - 主按钮（实心）
   - 次按钮（边框）
   - 禁用状态

3. **SearchBar** - 搜索栏
   - 图标 + 输入框 + 清除按钮

4. **TagChip** - 标签组件
   - 多种颜色变体

5. **EmptyState** - 空状态
   - 图标 + 提示文字 + 引导按钮

### 4.2 业务组件

1. **BorrowModal** - 借阅弹窗
2. **ActivityCard** - 活动卡片
3. **ReportChart** - 报告图表
4. **ChatBubble** - 对话气泡

---

## 5. 动画效果

- 页面切换: 淡入淡出 300ms
- 卡片悬停: 轻微上浮 + 阴影加深
- 按钮点击: 缩放 0.95 + 回弹
- 列表加载: 渐入 + 交错延迟
- 收藏成功: 心跳动画
- AI 回复: 打字机效果

---

## 6. 技术规格

- 框架: 微信小程序原生开发
- 适配: 750rpx 布局
- 存储: wx.setStorage 本地缓存
- 状态: Page data 管理
- 样式: CSS3 + flex 布局
